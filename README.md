Acest proiect folosește API‑ul RandomUser.me pentru a genera utilizatori aleatori. Aplicația preia date precum numele, emailul, țara și fotografia utilizatorului. Informațiile sunt afișate dinamic în pagină prin JavaScript. Designul este realizat cu HTML și CSS pentru o prezentare modernă și simplă. Proiectul demonstrează utilizarea Fetch API și manipularea DOM într-o aplicație web reală.
